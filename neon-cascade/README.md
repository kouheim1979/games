# NEON CASCADE（ネオン・カスケード）

[ブラウザで遊ぶ](https://kouheim1979.github.io/games/neon-cascade/)

同じ色をなぞって消し、爆発コアとオーバードライブで得点を伸ばすブラウザアクションパズルです。

- **60秒アタック** — 毎回変わる盤面でスコアを競います。
- **デイリー** — 日本時間で日替わり。同じ日なら初期盤面と補充の乱数が共通です。消し方でその後の盤面が変わります。
- **練習** — 時間制限なしで連鎖や強化の組み合わせを試せます。

同色のピースを3つ以上つなぎ、指やマウスを離すと消せます。ななめもつながります。5つ以上で爆発コアを作り、8つ以上で爆発範囲が広がります。コアはタップで起爆できます。爆風が別のコアに届くと連鎖爆発が起きます。

すばやく続けて消すとコンボ倍率が上がります。ゲージが満タンになったら「発動」で全コアを一斉起爆し、6秒間の得点が2倍になります。5回目と12回目の消去後に、それぞれ3つの候補から強化を1つ選べます。

キーボードでは盤面にフォーカスして Enter で選択・確定、矢印キーで移動、Q/E/Z/C でななめ移動します。Space でオーバードライブを発動し、Esc で選択を取り消すか一時停止できます。

スコアと設定は端末内に保存します。「遊び方」で演出を控えめにできます。日本語・英語・簡体字中国語・スペイン語に対応しています。

ローカルで遊ぶには、このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。依存パッケージのインストールやビルドは不要です。
