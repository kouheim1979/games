料理ゲーム用の画像セットです。元の絵文字を変える準備として、子ども向けの**クレヨン・色鉛筆風**と、以前の**つやつやしたイラスト風**を別々に保存しました。

- [材料34種類](kids/ingredients/) : ゲームで使われる材料名と同じファイル名

- [子ども向けZIP](kids-crayon-web.zip)

## 前回のイラスト風（10枚）

## 利用方法
このフォルダの `asset-map.json` にゲーム内の料理・材料と画像パスの対応をまとめています。

画像例:
- `assets/kids/dishes/curry.png`
- `assets/kids/dishes/onigiri.png`
- `assets/kids/ingredients/にんじん.png`

画像はいずれも背景透過PNGで、ゲームで軽快に使えるようWeb向けにリサイズ・圧縮した版です（料理など256px、材料160px）。
**既存のゲームコードは変更していないため、この時点では画面上の絵文字はそのままです。**

前回の大きな元画像ZIP、子ども向けの高画質ZIPは元の会話内に別途保存してあります。
