# おりょうり食堂

お客さんの注文を聞いて料理をつくる、お料理シミュレーションゲームです。外部ファイルなしの1ファイルHTML（フォントのみGoogle Fonts）。

## 遊び方

1. お客さんの注文を見て「つくる！」を押す
2. 工程を順にこなす
   - ざいりょう：レシピの材料だけをタップ
   - きる・にぎる：まな板を連打（はやいほど高得点）
   - やく・にる：メーターがみどりの範囲で火をとめる
   - まぜる：ボウルの中をぐるぐるなぞる（ボタンでも可）
   - かける・そそぐ：長押しして、みどりの範囲ではなす
3. 出来ばえで星1〜3つ。売上＋チップ（待たせるほど減る）がもらえる
4. 一日の終わりに売上を確認。お店の道具（包丁・フライパン・看板）を買うと調理が楽になる

メニューは8品（おにぎり・めだまやき・みそしる・パンケーキ・オムライス・カレーライス・ハンバーグ・ラーメン）。日ごとに増え、7日目で全品そろいます。

## 保存

日数・売上・道具・レシピ帳の記録は端末の localStorage（`ryouri-shokudo:v1`）にだけ保存します。日の途中でやめると、その日はやりなおしです。

## 多言語

画面の文言は `i18n/dict/ryouri-shokudo.js` で英語・簡体字中国語・スペイン語に切り替わります。文言を変えたら辞書も更新してください。
