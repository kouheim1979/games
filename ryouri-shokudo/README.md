# おりょうり食堂

お客さんの注文を聞いて料理をつくる、お料理シミュレーションゲームです。外部ファイルなしの1ファイルHTML（フォントのみGoogle Fonts）。

## 遊び方

1. お客さんの注文を見て「つくる！」を押す
2. 工程を順にこなす
   - ざいりょう：レシピの材料だけをタップ
   - きる・にぎる：まな板を連打（はやいほど高得点）
   - やく・にる：メーターがみどりの範囲で火をとめる
   - まぜる：ボウルの中をぐるぐるなぞる（ボタンでも可）
   - かける・そそぐ：長押しして、みどりの範囲ではなす
3. 出来ばえで星1〜3つ。売上＋チップ（待たせるほど減る）がもらえる
4. 一日の終わりに売上を確認。お店の道具（包丁・フライパン・看板）を買うと調理が楽になる

メニューは8品（おにぎり・めだまやき・みそしる・パンケーキ・オムライス・カレーライス・ハンバーグ・ラーメン）。日ごとに増え、7日目で全品そろいます。

## 新メニューづくり

タイトルの「新メニュー」（またはレシピ帳の「＋ 新メニューを つくる」）から、自分だけのメニューを考えて追加できます。

1. うつわ：おさら・どんぶり・グラスから選ぶ
2. ざいりょう：34種類から2〜5こ
3. つくりかた：きる・にぎる・やく・にる・まぜる・かける から3つまで（材料によって「いためる」「ゆでる」「そそぐ」「まるめる」になる）
4. しあげ：なまえ（「おまかせ」で自動）をつけて、ためたお金（ちょきん）から払う

- ねだんは材料とつくりかたの数で決まり（150〜700円）、払うお金はねだんの2倍
- できあがりの絵は、うつわ・材料・つくりかたから自動で描く（めだまやき・おにぎり・スープ・パフェなど）
- 追加した次の日（つぎに店をあけた日）に、少なくとも1回は注文が入る
- 自作メニューは6つまで。レシピ帳でなまえを変えたり、はずしたりできる（払ったお金はもどらない）
- つくりかけの新メニューも保存され、お金が足りないときは後で続きから払える

## 保存

日数・売上・道具・レシピ帳・自作メニュー（`custom`）・つくりかけ（`draft`）の記録は端末の localStorage（`ryouri-shokudo:v1`）にだけ保存します。日の途中でやめると、その日はやりなおしです。
