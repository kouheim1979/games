# ギリドカ

[ブラウザーで遊ぶ](https://kouheim1979.github.io/games/giridoka/)

長押しで敵を引きつけ、ぶつかる直前に指を離して一気に爆破する、度胸だめしのワンタップアクションです。ゲーム内の表示は日本語です。

- 画面を長押しすると爆破リングが広がり、敵が心臓めがけて加速します。指を離すとリングの中の敵がまとめて爆発します。
- 一番近い敵との距離が近いほど倍率が上がり、最大30倍です。爆発は近くの敵へ連鎖し、連鎖数が増えるほど1体ごとの点も増えます。
- 敵に当たると即終了（欲張りすぎ）。早く離してばかりだと度胸ゲージが尽き、終了します（ビビりすぎ）。ゲージが空になったあとも、長押ししていれば一度だけ「×6以上の爆破」で生き残るチャンスがあります。
- ゲージが満タンになるか金の星を巻き込むと、6.5秒間のフィーバーでスコアが3倍になります。
- 敵は通常、速いダーツ、遅くて高得点のヘビー、広く誘爆するバクダン、横切る金の星の5種類です。
- 終了後に「度胸判定書」が出ます。チキン度（どこまで引きつけたか）と判定、死因、最ギリの秒数を、XとLINEへワンタップで共有できます。
- 「結果を画像でシェア」で、度胸判定書を1枚の画像（1080×1350）にして共有できます。スマホでは共有メニューからX・LINE・インスタなどへ画像つきで送れます。共有メニューが使えない環境では、画像を長押し（PCは「画像を保存」「画像をコピー」）で使えます。
- 操作はスマホなら画面の長押し、PCならスペースキーの長押しです。自己ベストは端末に保存されます。

1ファイルで動くので、`index.html` を開くだけでローカルでも遊べます。依存パッケージのインストールやビルドは不要です。
