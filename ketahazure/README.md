# 桁外れ

玉を落として数をふくらませる、縁日ふうの玉落としゲームです。万、億、兆と桁を上げていき、無量大数（10の68乗）の先にある「桁外れ」を目指します。

遊ぶ: https://kouheim1979.github.io/games/ketahazure/

## あそびかた

- 画面にふれて左右に動かし、指をはなすと玉が落ちます。玉は釘やちょうちんに当たるたびに値がふえ、下の桝に入ると得点になります。
- 桝に入るたびに「勢い」が上がります。あとから落とす玉ほど高得点です。
- 当たった回数で祭ゲージがたまり、いっぱいになると玉がふってきます。
- ノルマをこえると札を1枚もらえます。ちょうちんは盤面の好きな場所に置けて、同じ種類を重ねるとLvが上がります（上限はステージの数）。
- 次のステージのノルマも100倍こえていたら、1ステージ飛び級して札を2枚えらべます。
- 落とす場所の真下にある釘（金色の印の下）は、どの玉もほぼ必ず当たる特等席です。ねらいは上2段の釘の真上に吸いつきます。
- パソコンでは左右キーでねらい、スペースキーで落とせます。Esc で一時停止です。

## しくみ

- `index.html` ひとつで動きます。外部ファイルも通信もありません。絵は Canvas、音は Web Audio でその場で合成しています。
- 最高記録と設定（音・速さ）だけを端末の localStorage に保存します。
- 数は命数法（万・億・兆・京・垓・𥝱・穣・溝・澗・正・載・極・恒河沙・阿僧祇・那由他・不可思議・無量大数）で表示し、それをこえると「10の何乗」で書きます。
- 公開ポータル（`portal/catalog.js`）には未掲載です。画面の多言語化（`i18n/`）にも未対応で、日本語のみです。

## バランス調整

ノルマの表（`index.html` の `QT`）は、自動プレイで測った得点の伸び方に合わせてあります。札やちょうちんの数字を変えたら測り直してください。

```sh
python3 ketahazure/balance-sim.py smoke              # 起動して1ステージ遊び、エラーが出ないか確かめる
python3 ketahazure/balance-sim.py growth smart 100   # ステージごとの得点分布（失敗なし・飛び級なし）
python3 ketahazure/balance-sim.py runs smart 100     # 通しで遊んだときの到達ステージとクリア率
```

方針は `smart`（札をよく選ぶ）、`casual`（札はでたらめ、置き場所はおまかせ）、`random`（すべてでたらめ）の3通りです。Python の Playwright と Chromium が必要です。

2026-11-13 の測定（各120回）:

| 方針 | クリア率 | 到達ステージの中央値 |
|---|---|---|
| smart | 60% | 25 |
| casual | 6% | 19 |
| random | 0% | 10 |

クリアした回は、遊んだステージ数の中央値が17、札は25枚でした。
