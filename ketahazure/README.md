# 桁外れ

玉を落として数をふくらませる、縁日ふうの玉落としゲームです。万、億、兆と桁を上げていき、無量大数（10の68乗）の先にある「桁外れ」を目指します。

遊ぶ: https://kouheim1979.github.io/games/ketahazure/

## あそびかた

- 画面にふれて左右に動かし、指をはなすと玉が落ちます。落とすのをやめるときは、画面下の「キャンセル」まで指を動かしてからはなします。
- 玉は釘やちょうちんに当たるたびに値がふえ、下の桝に入ると得点になります。
- 桝に入るたびに「勢い」が上がります。あとから落とす玉ほど高得点です。
- 当たった回数で祭ゲージがたまり、いっぱいになると玉がふってきます。音が入っていると、祭りの間はちんどん囃子が流れます。
- ノルマをこえると札を1枚もらえます。ほしい札を1回押すと確定します。ちょうちん札は配置画面に進みます。
- ちょうちんは好きな場所に置けて、同じ種類を重ねるとLvが上がります。
- タイトルの「盤面」から、千鳥・ひょうたん・川くだり・二またを選べます。次に遊ぶときも最後に選んだ盤面で始まります。
- 1投目から増えた玉も含め、その投の得点がノルマ以上なら「一発突破」で札を1枚追加します。次のステージのノルマの100倍以上なら、1ステージ飛び級してさらに札を1枚追加します。
- 「あそびかた」から、9種類のちょうちんの動きと札のチュートリアル動画を見られます。
- 落とす場所の真下にある釘（金色の印の下）は、どの玉もほぼ必ず当たる特等席です。ねらいは上2段の釘の真上に吸いつきます。
- パソコンでは左右キーでねらい、スペースキーで落とせます。数字キーの1〜3で札を選べます。Escで一時停止します。

## しくみ

- ゲームとちょうちんのデモは `index.html` で動きます。絵は Canvas、音は Web Audio でその場で合成しています。札の動画を開くと同じフォルダーの `ketahazure-card-tutorial.mp4` を読み込みます。
- 最高記録、自己ランキングと設定（音・速さ・盤面）を端末の localStorage に保存します。
- 数は命数法（万・億・兆・京・垓・𥝱・穣・溝・澗・正・載・極・恒河沙・阿僧祇・那由他・不可思議・無量大数）で表示し、それをこえると「10の何乗」で書きます。
- 公開ポータル（`portal/catalog.js`）には未掲載です。画面の多言語化（`i18n/`）にも未対応で、日本語のみです。

## バランス調整

公開の [GitHub Pagesシミュレーター](https://kouheim1979.github.io/games/ketahazure/?dev=balance) では `/ketahazure/?dev=balance` でシミュレーターを開けます。最新の本編と同じ物理・得点処理を使い、盤面の形（千鳥・ひょうたん・川くだり・二また）と難易度を選択して、同じ乱数シードで盤面A/Bを比較できます。本編の保存データは変更しません。

ノルマの表（`index.html` の `QT`）は、自動プレイで測った得点の伸び方に合わせてあります。札やちょうちんの数字を変えたら測り直してください。

```sh
python3 ketahazure/balance-sim.py smoke              # 起動して1ステージ遊び、エラーが出ないか確かめる
python3 ketahazure/balance-sim.py growth smart 100   # ステージごとの得点分布（失敗なし・飛び級なし）
python3 ketahazure/balance-sim.py runs smart 100     # 通しで遊んだときの到達ステージとクリア率
```

方針は `smart`（札をよく選ぶ）、`casual`（札はでたらめ、置き場所はおまかせ）、`random`（すべてでたらめ）の3通りです。Python の Playwright と Chromium が必要です。

2026-11-13 の測定（各120回）:

| 方針 | クリア率 | 到達ステージの中央値 |
|---|---|---|
| smart | 60% | 25 |
| casual | 6% | 19 |
| random | 0% | 10 |

クリアした回は、遊んだステージ数の中央値が17、札は25枚でした。

シミュレーターは本編と同一の hitPeg / stepBalls / land / startStage を使います。育ちの実測倍率、ステージ継続、16種のお守り、難易度による持ち玉数、追加投下、実処理の自己診断を搭載。A/B比較は初期配置からの独立試行です。演出と音は省略し、乱数を固定するため通常プレイと同一の軌跡を保証するものではありません。
