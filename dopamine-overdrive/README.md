# DOPAMINE OVERDRIVE

[ブラウザーで遊ぶ](https://kouheim1979.github.io/games/dopamine-overdrive/)

引いたユニットがコアを生み、増えたコアでさらにガチャを引く、無料のブラウザーゲームです。ゲーム内の表示は日本語です。

- 最初に5,200コア。1回100、10連900、50連4,250コアで召喚できます。
- 10連・50連では10枚ごとにSR以上が1体確定。SSR以上が49回続けて出なければ、次はSSR以上確定です。基本排出率と保証時の確率は、ゲーム内の「排出率」で確認できます。
- 30回引くたびに650コアを獲得し、フィーバーで15秒間コア発電が3倍。残り時間があるときは15秒を加算します。
- ユニットは全12体。同じユニットを2・4・8体と集めるごとに発電量が増えます。重複で出た欠片は発電炉の強化や未入手ユニットとの交換に使えます。
- 進行は端末に自動保存され、ゲームを閉じている間も最大8時間分のコアが貯まります。設定で効果音や開封演出を調整できます。

このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開けばローカルでも遊べます。依存パッケージのインストールやビルドは不要です。
