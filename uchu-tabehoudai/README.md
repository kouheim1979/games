# 宇宙食べ放題

[ブラウザーで遊ぶ](https://kouheim1979.github.io/games/uchu-tabehoudai/)

ブラックホールになって、テーブルの上の豆粒から宇宙まるごとまで食べ尽くす、成長型の食べ放題アクションです。ゲーム内の表示は日本語です。

- 吸い込むたびに音階が上がり、大きな物を食べると画面が揺れます。直径表示は mm から億光年まで単位が変わっていきます。
- 全13皿。次の皿へ進むと「延長」で時間が増え、残り10秒で「ラストオーダー」、終了後は伝票が出ます。
- 皿ごとのメイン料理は矢印で場所がわかり、コンボでフィーバー（吸い込み範囲拡大）が入ります。食べた物は216品の「お品書き」にたまります。
- 操作はスマホなら画面をなぞる仮想スティック、PCならWASD／矢印キーです。Escape／Pで一時停止します。
- クリアするとビッグバンが起き、また最初のテーブルから始まります。自己ベストと図鑑は端末に保存されます。
